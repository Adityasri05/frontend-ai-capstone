## 3. AI Observations & Diagnostics

### Which activities waste the most time?
Writing boilerplates, formatting project documentation, and translating designs into Tailwind utility classes consume the most time. These tasks are highly structured and repetitive, taking focus away from complex application logic.

### Which activities can AI improve the most?
AI can dramatically improve **UI styling iterations** and **documentation drafting**. Allowing AI to generate initial documentation saves hours, while AI-assisted styling helps me build interfaces faster.

### Which activities should always require human judgment?
**Making career choices, participating in team meetings, and architecting agent systems** must always require human judgment. AI cannot manage personal professional relationships or dictate long-term career strategies.

## 5. Three Target Tasks & Success Definitions

To measure my workflow performance, I have selected three target tasks that will be reused in future internship modules (FL-02, FL-03, and FL-04).

### Task 1: Generate React UI Components using Tailwind CSS
- **Why chosen**: High-frequency collaboration task that directly affects visual fidelity and speed in my FlyRank internship.
- **Success Definition (Measurable)**:
  - Component compiles with zero TypeScript errors under strict mode.
  - Component uses responsive Tailwind utility classes.
  - Meets WCAG AA contrast standards and uses semantic HTML elements.
  - Total code length is under 150 lines.
  - Zero ESLint warnings are triggered on save.

### Task 2: Writing & Summarizing PR/Project Documentation
- **Why chosen**: Writing and maintaining well-defined documentation is highly delegable, allowing me to save writing time.
- **Success Definition (Measurable)**:
  - Markdown summary of a git diff is generated in under 15 seconds.
  - Accurately details modified components, files, and configuration adjustments.
  - Requires less than 1 minute of manual human editing before finalize.

### Task 3: Writing Node.js API Endpoints & ML Integrations
- **Why chosen**: Aligns with my current learning roadmap (Node.js & ML) and my personal projects building AI agents.
- **Success Definition (Measurable)**:
  - API endpoint resolves and returns JSON payloads with valid HTTP status codes.
  - Contains strict type definitions for request bodies and response structures.
  - Correctly handles and catches asynchronous errors with clean try-catch blocks.
  - Compiles with zero compilation or runtime errors.
