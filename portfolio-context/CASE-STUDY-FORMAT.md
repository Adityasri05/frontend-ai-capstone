# Case Study Required Format

Every portfolio case study must adhere to the three-beat narrative structure:

```text
1. Problem (Who had the problem, what was difficult, why it mattered)
      ↓
2. What I Did (Engineering implementation, key decision, trade-off)
      ↓
3. What Came Of It (Verified outcome, performance, test coverage, deployment)
```

### Mandatory Requirements for Every Case Study:
- **Evidence**: Live URL, GitHub repo, source files, and screenshots (`.svg` or `.png`).
- **Limitation**: Must include at least one honest, real limitation.
- **AI Transparency**: Disclose where AI tools assisted and what was manually verified.
- **Tone**: Technical, concise, evidence-driven.
