# Voice & Writing Style Guide

## Guidelines for Portfolio Copy

### 1. Direct & Evidence-Based
- Use concrete, technical language.
- Lead with numbers, test results, code snippets, and architecture choices.
- Always include an honest limitation for every project.

### 2. Forbidden Words & Buzzwords
❌ **NEVER USE**:
- "Revolutionary"
- "Cutting-edge"
- "Seamless"
- "Next-generation"
- "Leverages AI"
- "Game-changing"
- "Industry-leading"
- "Mastered"

### 3. Sentence Structure
- Keep bullet points short and scannable.
- Start action points with active engineering verbs: *Architected, Engineered, Implemented, Built, Verified, Optimized, Benchmarked*.
