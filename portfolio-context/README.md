# Portfolio Context & Preserved Build Context Pack

This directory acts as the portable source of truth for **Aditya Srivastav's** portfolio identity, voice, technology stack, case study format, and project history.

---

## Purpose & AI Session Usage

When starting a new AI session (in Claude, Antigravity, Cursor, or ChatGPT) to write a new case study, refactor a page, or generate technical documentation:
1. Load or reference this `portfolio-context/` directory.
2. The AI assistant will immediately adopt your voice, brand colors, positioning, and architectural principles without needing to rebuild context from scratch.
