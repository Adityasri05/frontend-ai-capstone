# Technology Stack Matrix

This document provides a realistic breakdown of technologies used across the portfolio to prevent AI assistants from exaggerating skills.

---

## 1. Strong / Core Competencies
* **Frontend**: Next.js 15 (App Router), React 19, TypeScript, Tailwind CSS v4, HTML5 Canvas / WebGL (GLSL Shaders), Zustand.
* **AI Integration**: Vercel AI SDK (`ai`), `@ai-sdk/anthropic`, Anthropic Claude 3.5 Sonnet, Tool Calling (`scoreCandidate`), Prompt Engineering.
* **Backend & Proxies**: FastAPI (Python), Node.js / Next.js Serverless Route Handlers, REST API Design, IP Rate Limiting.
* **Testing & Tooling**: Vitest, React Testing Library, Playwright E2E, ESLint, Git, Netlify Edge CDN.

---

## 2. Practical Exposure / Learning Focus
* **AI / ML**: Vector RAG (tRPC / embeddings), PyTorch basics, Model Context Protocol (MCP) primitives.
* **Database**: Firebase Realtime DB & Firestore (Local storage fallbacks), SQLite / PostgreSQL basics.
* **Graphics**: Three.js / React Three Fiber (Procedural 3D mesh scenes).
